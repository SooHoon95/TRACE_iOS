한 줄 컨셉

여행지(그리고 동네)에서 경험 카드를 수집하면, 그게 자동으로 나만의 여행 정체성·지도로 합성되어 — 평생 쌓이고(D), 남들과 다르게 자랑할 수 있는(A) 개인 여행 도감 게임.

KYRO의 수집·진행 쾌감 + Spotify Wrapped의 자랑 포맷 + 셋로그의 인증 감성을, 영역전(밀도 의존) 없이 개인 베이스로.

🎯 문제 정의 (problem-first · 데이터 검증)

고객

2030 — 자주 다니고, SNS 인증 적극적, 뻔한 코스보다 능동 체험을 찾는 여행자

PAIN

"내 여행이 남들과 똑같고(A), 끝나면 사진뿐 안 남는다(D)"

🏛️ 두 기둥

①

경험 카드 (컬렉터블)

장소가 아니라 경험/순간이 단위. 「한라산 일출」「해녀 만나기」「숨은 로컬식당」 = 희귀도 있는 카드. 같은 카페에서도 여러 장.

능동 체험 유도희귀도덱 = 나의 취향
②

자동 여행 정체성 (Wrapped)

모은 카드가 합쳐져 「산<바다·도시형·새벽 탐험가」 같은 시각적 여행 지문으로 자동 진화. 한 장으로 자랑(A) + 평생 누적(D).

레이더 차트칭호발자취 지도

✨ 정체성 합성 — 어떻게 (AI 없이, 집계로)

  1. 취향 그래프 — 카드 카테고리(자연·맛집·액티비티·문화·카페…)별 보유 비율 → 레이더 차트 (집계 쿼리)
  2. 칭호 — 임계값 배지 테이블: "카페 10개 = 카페 헌터", "일출 5회 = 새벽 사냥꾼"
  3. 발자취 지도 — 수집 카드 GPS를 핀·히트맵으로 (MapKit, 클라이언트 렌더)
  4. 희귀도 — "100명 중 N명만 보유" 상대 희귀도 → 수집 욕구 + 자랑 욕구 동시 자극
⚠️ 검증 지적: "합성"이 밋밋하면 Wrapped가 아니라 통계 대시보드. → 공유 비주얼 퀄리티를 최우선 투자(바이럴 = 1차 방어벽). "진화(시간축 비교)"는 P1.

🌗 일상 + 여행, 둘 다 작동 (리텐션 핵심)

개인 수집은 밀도 없이도 동네에서 굴러간다(영역전과 결정적 차이). 그래서 "여행 안 가는 345일"에도 죽지 않음.
