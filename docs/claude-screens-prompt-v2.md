# claude.ai/design — TRACE 화면 v2.3 (claiming 엔진 · Pretendard 단일)

> 디자인 시스템 먼저 만든 뒤 같은 프로젝트에 붙여넣어 화면 생성. 폰트 Pretendard만.

---

```
TRACE 앱 화면을 만들어줘(모바일 iOS). 위 TRACE 디자인 시스템 컴포넌트·토큰으로 조립. 폰트 Pretendard만.

컨셉/엔진: 실제 장소가 시간캡슐. Day-1 동기는 "이 자리에 내 순간을 남기는 쾌감(claiming) + 남들이 여기 남긴 걸
보는 FOMO". 남기면 즉시 그 장소 '모두의 순간'에 합류. 톱N은 부가 큐레이션, 재방문 소환은 데이터 쌓이면 나중에
등장하는 보너스. 톤: 라이트 페이퍼(전시·순간·공유) + 웜 다크(지도·AR), 코랄 포인트.

만들 화면 (claiming 중심 순서):
1. ★온보딩 첫 claim — "이 자리에 네 첫 순간을 남겨" → 사진+한마디 → 즉시 장소에 합류하는 쾌감 연출. 가장 공들여.
2. ★순간 남기기(claiming 모달) — 카메라 → "여기 N명이 남겼어"(기존 순간 슬쩍 노출·FOMO) → 한마디+동행+무드+공개범위
   → "이 자리에 남기기" → 내 마크가 장소에 박히는 합류 피드백.
3. ★홈(활동·주변) — 🔥방금 남들이 남긴 순간(활동 피드) + 📍내 주변 남길 자리 + ✨추천 전시. 라이트 페이퍼.
4. 장소 전시 — 모두의 순간 그리드 + 큼직한 "너도 남겨" CTA + 톱N(부가) + 통계. 라이트 페이퍼.
5. 지도 — PlacePin(기억 밀도) + 내 발자취. 웜 다크.
6. 도감 — 내가 남긴 순간·다녀간 장소(MomentCard 그리드).
7. 여행 정체성 Wrapped — 공유 카드.
8. (emergent) 재방문 레거시 소환 — 같은 장소에 내 과거 쌓였을 때 ReturnTimeline.
9. (P1/P2) AR 모자이크 / AR 포털 전시회장 — 현장 발굴.

먼저 1·2번(첫 claim, 순간 남기기)부터 — 업로드 엔진이 여기 다 있음. 그다음 3(홈), 4(전시).
```

---

**순서 팁:** 1·2(claiming) → 3(홈 활동) → 4(전시) → 5(지도) → 6·7 → 8·9. **1·2가 엔진이라 제일 공들여.** 재방문(8)은 이제 후순위(emergent).
