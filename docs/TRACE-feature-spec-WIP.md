## 화면별 명세

> 각 화면 공통 항목:
> **목적** / **진입(트리거)** / **핵심 동작(스텝)** / **화면 요소(컴포넌트)** / **데이터(보여줄 것·출처)** / **상태·엣지케이스** / **인터랙션·전환·애니메이션** / **구현 방식(클라·서버·AR)** / **미정·질문**

### 1. 재방문 / 레거시 소환 ★ (앱의 심장)
- 목적:
- 진입(트리거): _GPS 도착 자동? 알림 탭? 수동 진입? 어디까지 가까워야?_
- 핵심 동작(스텝): 1) 2) 3)
- 화면 요소(컴포넌트): _ReturnTimeline 등_
- 데이터(보여줄 것·출처): _내 과거 방문들 — 무엇을, 몇 개, 정렬은?_
- 상태·엣지: _첫 방문(과거 없음) / 1번만 옴 / 동행자 없음_
- 인터랙션·전환·애니메이션: _시간층이 어떻게 "펼쳐지나"_
- 구현 방식:
- 미정·질문:

### 2. 장소 전시 (원격 갤러리)
- 목적:
- 진입(트리거): _지도 핀 탭? 검색? 공유링크?_
- 핵심 동작(스텝):
- 화면 요소: _ExhibitionTile / 톱12 그리드 / TopBadge / 통계_
- 데이터(보여줄 것·출처): _커버·톱N·기여자수·통계(이 숫자들 뭐임?)_
- 상태·엣지: _전시 비어있음 / 톱12 미달 / 내가 이미 기여_
- 인터랙션·전환·애니메이션:
- 구현 방식: _원격 = 어디서든. 사진 로딩·페이지네이션_
- 미정·질문:

### 3. 지도 / 탐색

- 데이터(보여줄 것·출처): _어떤 장소가 핀으로? 전시 있는 곳만? 내 발자취?_
- 상태·엣지: _주변에 아무것도 없음_

### 4. 순간 남기기 (CaptureComposer)
- 목적:
- 진입(트리거): _현장에서만? 나중에도? 사진은 그 자리서 찍기만 / 갤러리 허용?_
- 핵심 동작(스텝):
- 화면 요소: _사진 프레임 / 한마디 / 동행 / 무드_
- 데이터(저장할 것·어디에): _사진·메타·GPS·공개범위_
- 상태·엣지: _위치 불명확 / 오프라인_
- 인터랙션·전환·애니메이션:
- 구현 방식: _현장 인증(카메라+GPS+시각)? 백업?_
- 미정·질문:

### 5. AR 모자이크 (현장 글랜스)

- 화면 요소:
- 데이터(보여줄 것·출처): _그 스팟 사진들 — 몇 장, 어떤 기준_
- 상태·엣지:
- 인터랙션·전환·애니메이션: _탭하면? 가까이 가면?_
