# TRACE — 전체 앱 플로우 & 화면 설계 (v2.1 · claiming 엔진)

> Day-1 엔진 = **claiming(마킹의 쾌감) + 상호성/FOMO**. 톱N=부가 큐레이션, 재방문=emergent 장기보상.
> 열린 질문 4개는 내가 결정(⚙️) — 뒤집어도 됨.

## ⚙️ 확정된 열린 결정
1. **홈 = "활동·주변" 피드** (순수 둘러보기 아님): *방금 남들이 남긴 순간* + *내 주변 남길 자리* + 추천 전시. → FOMO 점화 + claiming 유도. 지도는 별도 탭.
2. **친구/팔로우 = MVP엔 없음** (장소-집단 중심). 동행 태그만. 친구 초대는 P1.
3. **게스트 범위:** 둘러보기(전시 보기) = 게스트 OK / **남기기·도감·레거시·백업 = 가입 필요.**
4. **순간 남기기 = 현장 우선** (앱내 카메라+GPS 인증). 갤러리 업로드는 무결성 위해 제한(같은 방문 내 보정만 P1).

## A. 네비게이션
```
앱 실행
 ├─ [미인증] 스플래시 → 로그인(Apple·Kakao·게스트) → 온보딩(권한 + 첫 claim) → 메인
 └─ [인증] 메인 탭

메인 탭 (하단 5)
 [ 🏠 홈(활동·주변) ]  [ 🗺️ 지도 ]  [ ＋ 남기기 ]  [ 📖 도감 ]  [ 👤 나 ]
                            └ 중앙, claiming 모달 (코어 액션)
```

## B. 코어 루프 (claiming 중심)
```
이 자리에서 순간 포착 → 남긴다(claim·0초)
   → [즉시] 이 장소 '모두의 순간'에 내 마크 합류 (합류 애니메이션·피드백)
   → 그 자리 남들 순간이 보임 (FOMO·소속)
   → 다른 자리에서 또 남김
재방문/레거시 = 루프가 쌓여 나중에 emergent하게 등장 (장기 리텐션)
```

## C. 화면 인벤토리

| # | 화면 | 핵심 |
|---|---|---|
| 1.1 | 스플래시 | 자동 로그인 체크 |

| 1.5 | **첫 claim ★** | 현 위치에 첫 순간 남기기 → 즉시 장소 합류 쾌감 체험 (aha) |

| # | 화면 | 섹션 |
|---|---|---|

### 3. 🗺️ 지도 — 탭2

### 4. ＋ 순간 남기기 (claiming 모달) — 탭3 ★ 코어
| 스텝 | 내용 |
|---|---|
| a | 앱내 카메라로 현장 촬영 (또는 방금 찍은 것) |
| b | **그 자리 기존 순간 슬쩍 노출** ("여기 N명이 남겼어" — FOMO) |
| c | 한마디 + 동행(Companion) + 무드(Vibe) + 공개범위 |
| d | "이 자리에 남기기" → **즉시 합류 피드백**(내 마크가 장소에 박히는 연출) |

| 5.2 | 순간 상세 | 사진 풀뷰 + 한마디·동행·날짜·작성자·반응 |

## D. 핵심 시나리오
- **현장:** 홈/지도 → 장소 → (FOMO)기존 순간 봄 → **남긴다(claim)** → 즉시 합류
- **원격:** 홈 활동피드 → 추천 전시 둘러보기 → 가고픈 곳 위시
- **장기(emergent):** 데이터 쌓이면 → 오늘의 기억·재방문 소환 → Wrapped 공유
