## 0. 한 줄 정의

> **TRACE의 "경험 카드 수집"을, 유저가 실제 장소에 남긴 흔적을 AR로 찾아내고 그 자리에서 자기 흔적도 0초로 남기는 공개 UGC 보물찾기로 구현한다. 도감·정체성 합성은 TRACE 원본 그대로 유지한다.**

## 2. 코어 모델 — 한 그릇, 두 트랙

도감에 두 종류 수집물이 흘러들되, **정체성 가중치가 다르다.**

| | 🏛️ 운영 경험카드 (CuratedCard) | 🎨 유저 흔적 (Trace) |
|---|---|---|
| 누가 | 운영/AI 시딩 | 유저가 직접 |
| 단위 | 경험·행위 ("한라산 일출") | 사진+한마디+vibe태그(+선택 스티커) |
| 역할 | cold-start 백본 + 정체성 합성 근거 | 탐험·소셜·바이럴·연쇄 엔진 |
| 정체성 가중 | **풀(full)** | **P0: 0 (큐레이션만 합성) / P1: 검증된 흔적만 약하게** ← 스팸 오염 차단 |
| 모더레이션 | 불필요 | 필수 |

**안전핀 규칙:** "발견·탐험·자랑은 두 트랙 다, 정체성은 큐레이션 위주." → TRACE 품질 유지 + UGC 개방 허용.

### 온톨로지 (TRACE 원본 + 신규/변경)

- **User**: 닉네임, 여행정체성, 도감 + `[신규]` 내 흔적·"N명이 봄/수집" 카운터
- **Collectible**(부모) → `CuratedCard`(제목·장소·카테고리·희귀도·사진가이드·난이도) / `[변경] Trace`(제작자·사진·한마디·vibe태그·GPS·생성시각·수집카운트·선택 스티커)
- `[신규]` **Spot(장소)**: 흔적들이 stack되고 heat(열기) 보유 → 핫스팟 시각화 단위
- **Capture(인증)**: 사진·GPS·시각 — 획득 증명 (TRACE 원본)
- `[신규]` **Hunt(탐색 세션)**: 따뜻/차가움 거리 계산 → 리몰 판정
- **TravelIdentity**: 취향그래프·칭호·발자취지도 — CuratedCard 위주 합성

### 코어 루프

```
발견(주변 레이더: 카드+흔적 핀, 핀 열기=누적 흔적 수)
  → 접근(따뜻/차가움 AR 내비)
  → 리몰(카메라 켜면 2D 빌보드 등장)
  → 인증·획득(현장 사진+GPS+EXIF)
  → 도감 적재
  → 합성(정체성 — 큐레이션 위주)
  → 자랑(공유)
  → 기여(그 자리서 내 흔적 0초 남기기 → 남이 수집)  ← 연쇄 엔진
```

## 3. AR 보물찾기 메커니즘

**찾기와 남기기가 한 동선에서 끊김 없이 연속**되는 것이 설계의 심장. (레버 ② 발견=남기기 트리거를 구조적으로 보장.)

1. **발견(지도/레이더):** 주변 스팟 핀. 핀 크기·열기 = 쌓인 흔적 수. 큐레이션 카드 = 특별 핀(금색).
2. **접근(따뜻/차가움):** GPS 거리로 "따뜻/차가움"+방향. 정확좌표 숨김(보물찾기 맛). ~10–15m 진입 시 다음 잠금해제.
3. **리몰(카메라 AR):** 카메라 켜면 그 스팟에 쌓인 흔적이 2D 빌보드로 공중에 등장(사진 카드들 + 옵션 스티커). 큐레이션이면 해당 경험카드 등장.
4. **획득·인증:** 현장 카메라+GPS+EXIF 1장 → 도감 적재.
5. **남기기(0초) ⭐:** 방금 찍은 사진 + 한마디 + vibe 태그 1탭 → 내 흔적이 스팟에 쌓임. "여기 N명이 남겼어. 너도?" 넛지(🅲️ relay).
6. **창작 옵션(P1):** 그리고 싶으면 스티커·낙서 얹기(🅰️ 생존).

- **④→⑤가 한 화면 연속** = 찾은 직후 그 자리서 바로 남김 → 트레드밀이 아니라 연쇄.
- **AR 기술:** 2D 빌보드(GPS 앵커 + 카메라 오버레이) + ARKit 평면감지 정도. 모든 폰·온디바이스·무료.

## 4. cold-start + 안전/모더레이션

### cold-start — 투트랙 구조에 답이 박혀있음

- **운영 시딩 백본**(TRACE FX9): 핫플 반경 2km에 최소 30장·카테고리 5개+ → 첫 유저도 빈 지도 안 봄
- **단일 구역 밀집**(TRACE·거점 교훈): 전국 분산 ❌. 첫 런치 = 핫플 한 구역(제주 PoC = 특정 라이딩 코스)
- **0초 흔적 = 빠른 UGC 전환**: 스티커 대비 누적 가속
- **핫스팟 시각화**(레버 ③): 누적이 다음 사람을 흡인
- **제주 10명 = 시드 크루**: 출발 전/초반 흔적 미리 주입

### 안전/모더레이션 (P0 타협 불가)

위험: (a) 부적절 콘텐츠(앱스토어 리젝+이탈), (b) 물리적 안전(위험 장소 유인).

| # | 방어 | 막는 것 |
|---|---|---|
| 1 | 현장 인증 강제(앱내 카메라+GPS+EXIF 30초, 갤러리 차단) | 가짜·원격 어뷰징 |
| 2 | AI 1차 필터(사진·텍스트 음란·폭력·혐오) | 앱스토어 리젝 |
| 3 | 신고 + 반복신고 자동숨김 | 탐지·제지 |
| 4 | 장소 안전 게이트(사유지·절벽·선로·도로 지오펜스 블랙리스트, 야간 유도 자제) | 물리적 사고 |

개인 도감 모델이라 직접 피해자는 적음 → 무결성은 "가볍게+탐지" 수준으로 P0 감당 가능.

## 5. 기술 아키텍처 + 비용

### 스택 (TRACE 확정 스택과 동일 → 흡수 깔끔)

- **클라(iOS):** Swift/SwiftUI · ARKit 평면감지+2D 빌보드 · CoreLocation(거리/지오펜스) · KakaoMap 또는 NaverMap (핀/히트맵/발자취) · 정체성 합성=클라 집계 쿼리(AI 없이, FX1)
- **백엔드(무료티어):** Supabase/Firebase(인증·DB·메타데이터) · **Cloudflare R2**(사진, egress $0) · FCM(푸시) · AI 모더레이션(온디바이스 1차+서버 2차)

### 비용 — 비용포인트는 사진 스토리지뿐 (egress $0이 핵심)

가정: 흔적 1개 ≈ 200KB(720p WebP+썸네일). R2 단가(저장 $0.015/GB·월, 쓰기 $4.5/M, 읽기 $0.36/M, egress $0).

| 단계 | 규모 | 누적 사진 | R2 월 비용 | 올인(R2+DB+애플) |
|---|---|---|---|---|
| 제주 PoC | 10명·5일 | 0.6GB | **$0** | ≈ $8/월(애플뿐) |
| 동네 런치 | 1,000 MAU·1년 | 28.8GB | **$0.28 (≈380원)** | ≈ $8/월 |
| 성장 | 50,000 MAU·1년 | 1.4TB | **$36.75 (≈5만원)** | ≈ $70/월(≈9만원) |
| 대형 | 500,000 MAU·1년 | 14.4TB | **$478 (≈64만원)** | 월 50만원대 (이땐 수익모델 가동) |

- 큰 숫자의 ~90%는 저장+읽기 → **콜드 흔적 TTL/저화질 아카이빙 + 썸네일 우선/온디바이스 캐싱**으로 평탄화(위 표는 안 지운 최악값).
- **크루릴(영상)이 죽은 비용 리스크가, 사진+온디바이스 AR 구조에선 검증 끝까지 0에 수렴.** 처음부터 못 피하는 돈은 **Apple 개발자 $99/년**뿐.

## 6. MVP 범위 + 성공기준

### MVP 범위 (YAGNI — TRACE §13 계승)

- **✅ P0 (제주에서 우리 10명이 실제로 쓰는 것):** 운영 큐레이션 카드 시딩 · AR 보물찾기 코어 동선(발견→따뜻/차가움→카메라 리몰→현장인증 획득) · **흔적 남기기 0초** · 핫스팟 시각화 · 도감+정체성 합성 기본(큐레이션 위주) · 공유 · 온보딩 첫 흔적(FX3) · 안전 P0(현장인증·AI필터·신고·지오펜스)
- **⏳ P1:** 유저 스티커 창작(🅰️) · 위시리스트 알림 · 스폰서 카드(B2B2C) · 정체성 진화(시간축) · 동적 희귀도 · relay 넛지 고도화
- **🔮 P2:** 경쟁·그룹 레이어(위치검증 강화) · AI 추천 · 3D 공간 앵커 AR

### 성공기준 (정량 가설검증)

| 가설 | 지표 |
|---|---|
| ⭐ **H연쇄 (소비→생산)** | 흔적 찾은 사람 중 자기 흔적 남기는 **전환율** + 스팟당 누적 흔적 증가 추세 ← *모델의 생사* |
| H1 (찾기가 재밌나) | 세션당 발견·수집 수, 여행 1회당 수집 수 |
| H2 (공유가치) | 정체성/도감 공유율 ≥ 25%, 바이럴계수 K |
| H3 (재방문) | 2회차 재사용 ≥ 40%, D7 리텐션 ≥ 30%(일상모드 D30) |
| BM | 잠재 스폰서 LOI 1건 |

**H연쇄가 1순위.** 일정 % 미달 시 = 트레드밀 신호 → 흔적 UX 재설계.
