# claude.ai/design — TRACE P0 상세화면 (dev-ready) v3

> **사용법:** 컴포넌트가 올라간 기존 **TRACE Design System** 프로젝트에 붙여넣어 화면 생성.
> 한 번에 다 돌리지 말고 **배치(Batch) 1→4 순서로** 하나씩 붙여넣어. 폰트는 **Pretendard만**.
> 각 배치 프롬프트는 코드펜스 안 내용만 복사해서 붙여넣으면 됨.

---

## 공통 규칙 (모든 배치에 적용 — 첫 배치 붙여넣을 때 한 번만 같이)

```
[전역 규칙 — TRACE P0 화면]
- 폰트: Pretendard 단일. 위계는 weight(400~800)+크기로만. 세리프/장식폰트 금지.
- 두 서피스: 라이트 페이퍼(인증·전시·순간·도감·나) / 웜 다크(지도). 둘 다 코랄 포인트.
- 디바이스: iPhone, iOS 안전영역 준수. 하단 탭바 5개: [🏠 홈] [🗺️ 지도] [＋ 남기기(중앙·코랄 강조)] [📖 도감] [👤 나].
- 컨셉/엔진: 실제 장소가 시간캡슐. Day-1 동기 = 내 순간(사진) 남기는 쾌감(claiming) + 남이 여기 남긴 걸 보는 FOMO.
  남기면 즉시 그 장소 "모두의 순간"에 합류. 톱N·재방문은 P1(지금 화면엔 넣지 마).
- 위에서 만든 디자인 시스템 컴포넌트/토큰으로만 조립. 새 색·새 폰트 만들지 마.
- 화면마다 반드시 "빈 상태(empty)"도 같이 그려줘.
- 카피는 아래 명시한 한국어 그대로 써.
```

## Batch 1 — 인증·온보딩 (claiming 각인)  ※ 라이트 페이퍼

```
TRACE 인증·온보딩 화면을 만들어줘. 라이트 페이퍼 서피스. 컴포넌트: TraceButton, Avatar, CaptureComposer, JoinFeedback.

S1. 스플래시
- 역할: 자동 로그인 체크 중 잠깐 보이는 화면.
- 레이아웃: 중앙에 TRACE 워드마크(Pretendard 800, 큼직) + 그 아래 한 줄 태그라인 "이 자리에 남긴 순간들". 하단에 아주 작은 로딩 인디케이터.
- 배경: paper50, 코랄 아주 옅게 한 점.

S2. 로그인
- 역할: 첫 진입. 가입 마찰 최소.
- 레이아웃(위→아래): 상단 1/3 감성 비주얼(장소 사진 모자이크 느낌, 옅게) + 워드마크 / 중앙 카피 "여행이 끝나도, 그 자리엔 네 순간이 남아." / 하단 버튼 스택:
  · "Apple로 계속하기"(검정, 애플 로고) · "카카오로 계속하기"(카카오 옐로우) · "둘러보기(게스트)"(ghost 버튼, 작게).
- 하단 미세 카피: "게스트는 전시 구경만 — 남기려면 가입이 필요해요."

S3. 온보딩 2컷 (가로 스와이프 2페이지 + 점 인디케이터)
- 컷1: 큰 일러스트/사진 위 "이 자리에, 네 순간을 남겨" / 서브 "사진 한 장이면 충분해."
- 컷2: 같은 장소에 여러 사진이 켜켜이 쌓인 그리드 위 "남들의 순간이 여기 쌓여있어" / 서브 "그리고 너도 합류하는 거야."
- 하단: "다음" → 마지막 컷에선 "시작하기".

S4. 권한 priming (전체화면 시트 3연속, 각각 맥락 카피 + 허용 버튼)
- 위치: "지금 이 자리를 알아야 순간을 남길 수 있어요" → [위치 허용]
- 카메라: "현장에서 직접 찍은 사진만 남겨요(갤러리 업로드는 없어요)" → [카메라 허용]
- 알림: "내가 남긴 자리에 누가 합류하면 알려줄게요" → [알림 허용] / [나중에]

S5. 첫 claim ★ (가장 공들여 — aha 모먼트)
- 역할: 가입 직후 현 위치에서 첫 순간을 남겨 "합류" 쾌감을 즉시 체험.
- 레이아웃: 상단 "네 첫 순간을 남겨봐 📍성산일출봉" / 중앙 CaptureComposer(사진 프레임=촬영 CTA, 한마디·동행·무드 전부 '(선택)', 공개 토글) / 하단 "이 자리에 남기기".
- 제출 직후 화면: JoinFeedback — 내 마크가 장소에 '박히는' 연출 + "이 자리에 합류했어 ✨ 너가 N번째야".
- 빈/초기 상태: 사진 없으면 제출 버튼 비활성(흐리게).
```

## Batch 2 — claiming 엔진 (코어 루프)  ※ 라이트 페이퍼

```
TRACE 순간 남기기·장소 전시 화면을 만들어줘. 라이트 페이퍼. 컴포넌트: CaptureComposer, MomentCard, VibeTagChip, CompanionTag, TopBadge, JoinFeedback, SectionHeader, TraceButton.

S6. 순간 남기기 (claim 모달, 시트로 올라옴) ★
- 레이아웃(위→아래):
  · 사진 프레임: "📷 이 자리에서 촬영하기"(미촬영) / 촬영 후엔 사진 채워짐.
  · 헤더: "이 자리에 남기기 · 📍성산일출봉 · 여기 4명이 남겼어"(기존 순간 슬쩍 노출=FOMO).
  · "한마디 남긴다면… (선택)" 큰 굵은 입력.
  · "누구와 (선택)": CompanionTag 4개(연인/가족/친구/혼자), 토글 선택.
  · "무드 (선택)": VibeTagChip 6개(차분/활기/풍경/맛집/모험/숨은곳).
  · 공개범위 토글: "전시에 공개 / 이 자리의 '모두의 순간'에 합류해요" ↔ "나만 보기 / 이 순간은 나만 볼 수 있어요".
  · 하단 "이 자리에 남기기"(사진 있어야 활성).
- 필수는 사진 1장뿐. 나머지 비워도 제출 가능.

S7. 합류 피드백 (S6 제출 직후)
- 풀스크린 짧은 연출: 내 사진이 그리드 맨 위에 '톡' 박히고 "이 자리에 합류했어 ✨" 토스트 + "여기 N명이 남겼어" 카운트 +1.

S8. 장소 전시 ★ (콘텐츠 허브)
- 헤더: eyebrow "장소 전시" / 큰 장소명 "성산일출봉"(Pretendard 800) / "여기 4명이 순간을 남겼어".
- 본문: **모두의 순간 = 최신순 2열 그리드**(MomentCard 컴팩트: 사진+한마디+동행·무드 칩). 내가 남긴 건 살짝 강조 테두리.
- 하단 고정 CTA: 코랄 "＋ 너도 여기 남겨".
- (부가, 작게) 상단 한 칸에 TopBadge 단 '오늘의 순간' 1개 — 톱N은 P1이라 라벨만, 랭킹 로직 X.
- 빈 상태: "이 자리의 첫 순간이 되어줘" + 큰 ＋.

S9. 순간 상세 (그리드에서 사진 탭)
- 사진 풀뷰(상단 대형) + 한마디(굵게) + 작성자 Avatar+닉네임 + 날짜 + 동행·무드 칩 + 장소명.
- 액션 바: 하트(반응) · 공유 · "⋯" → 시트로 [신고하기] [숨기기]("이 순간 내 화면에서 가리기"). 신고/숨김 누르면 그리드에서 사라지는 토스트.
```

## Batch 3 — 발견 (홈·지도·도감)

```
TRACE 발견 화면을 만들어줘. 홈/도감은 라이트 페이퍼, 지도는 웜 다크. 컴포넌트: ActivityFeedItem, PlacePromptCard, ExhibitionTile, SectionHeader, MomentCard, PlacePin, Avatar, TabBar.

S10. 홈 (활동·주변)  ※ 라이트 페이퍼, 탭1
- 상단: 인사 "오늘은 어디에 남길까?" + 우상단 Avatar.
- 섹션1 SectionHeader "🔥 방금 남들이 남긴 순간": ActivityFeedItem 가로 스크롤(작은 썸네일+장소+동행+"3분 전") — FOMO.
- 섹션2 "📍 내 주변 남길 자리": PlacePromptCard 리스트(장소명+거리 "120m"+"너도 남겨" 미니 CTA) — claiming 유도.
- 섹션3 "✨ 둘러볼 전시": ExhibitionTile 가로 스크롤(커버+장소명+"N명").
- 빈 상태: 활동 없으면 "아직 조용하네 — 네가 첫 순간을 남겨봐" + ＋.

S11. 지도  ※ 웜 다크, 탭2
- 풀스크린 지도 + PlacePin: 전시 있는 곳(기억 밀도로 핀 크기·열기 다르게) / 내가 다녀간 곳(코랄 표시).
- 핀 탭 → 하단 미리보기 카드 슬라이드업(커버+장소명+"N명이 남김"+[전시 보기][여기 남기기]).
- 우하단 "현재 위치" 버튼. 상단 살짝 떠 있는 검색 힌트는 비활성(P1).
- 빈 상태: 주변에 핀 없으면 "이 근처는 아직 비어있어 — 첫 핀을 꽂아봐".

S12. 도감 (내 순간)  ※ 라이트 페이퍼, 탭4
- 상단 요약 바: "남긴 순간 12 · 다녀간 장소 5".
- 토글: [순간] / [장소].
  · 순간: 내 MomentCard 최신순 2열 그리드(나만 순간엔 '나만' 잠금 뱃지).
  · 장소: ExhibitionTile 그리드(내가 기여한 장소).
- 빈 상태: "아직 남긴 순간이 없어 — 지금 이 자리에서 시작해" + ＋.
```

## Batch 4 — 나·설정·빈상태  ※ 라이트 페이퍼

```
TRACE 나·설정 화면을 만들어줘. 라이트 페이퍼. 컴포넌트: Avatar, SectionHeader, TraceButton, IdentityCard(자리만, 내용은 P1).

S13. 나 / 프로필  (탭5)
- 상단: 큰 Avatar + 닉네임 + "여행자 · 2026.06 합류".
- 통계 3칸: 순간 / 장소 / 합류한 자리.
- (P1 자리표시) "여행 정체성 카드 보기" 버튼 — 눌러도 "준비 중" placeholder. 실제 Wrapped 내용은 P1.
- 하단 "설정" 진입 행.

S14. 설정
- 섹션 계정: 닉네임 변경 · 로그인 제공자 표시(Apple/Kakao) · 로그아웃(코랄 텍스트).
- 섹션 백업: "클라우드 백업: 켜짐(자동)" 상태만 표시(토글 아님) + "마지막 백업: 방금".
- 섹션 공개: "새 순간 기본 공개범위" = [전시 공개]/[나만] 선택.
- 섹션 안전: 차단/신고 내역 · 약관 · 개인정보.
- 게스트로 들어온 경우: 백업·공개 섹션 자리에 "가입하면 백업과 도감을 쓸 수 있어요" + [가입하기].

S15. 빈 상태 모음 (한 보드에 모아 그려줘)
- 홈 empty / 지도 empty / 도감 empty / 장소 전시 empty / 검색 비활성(P1) — 각각 한 줄 카피 + 큰 ＋ 또는 안내 아이콘. 톤 일관.
```

## 개발 연결 노트 (디자인 승인 후 내가 코드로)

- 이미 코드에 있는 것(재사용): 디자인 시스템 14컴포넌트(UIComponent), **장소 전시(S8)·순간 남기기(S6)는 SwiftUI로 이미 작동** — 디자인은 이 둘과 어긋나지 않게 맞추면 리워크 0.
- 화면 승인되는 대로 모듈 매핑대로 구현: 로그인·설정→Identity, 온보딩·첫claim→Onboard, 홈→MainTab, 지도→Map, 남기기·전시·상세→LeaveTrace, 도감→Collection, 탭루트→Router+MainTab.
- 데이터는 P0 동안 InMemoryTraceStore(목업) → Phase 2에서 Supabase+R2로 교체(PhotoStore/Repository 프로토콜 뒤라 화면 코드 안 바뀜).
```
