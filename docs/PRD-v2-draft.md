# 📋 TRACE 기획서 (PRD v2.0 · 발굴/레거시 모델) — 초안

> **TRACE** — "다닌 만큼, 내가 된다."
> 실제 장소가 **시간캡슐**이 되는 여행 앱. 장소에 남긴 사진 순간이 평생 쌓이고, 그 자리에 다시 서면 과거가 **발굴**된다. 모두의 순간은 그 장소의 **큐레이션 전시**가 된다.
> *상태: v1.0(AR 보물찾기) → v2.0(발굴/레거시) 개정 초안 · 확인 대기*

## 0. 이 개정의 위치 (피벗 아님, 정수)
v1.0은 "AR 보물찾기 × 수집·희귀도 게임"이었다. v2.0은 **게임 레이어(보물·희귀도·도감 경쟁)를 덜어내고**, 그 밑에 있던 진짜 가치 — **"장소에 켜켜이 쌓이는 내 인생(레거시)"** — 를 코어로 끌어올린다. AR은 별도 게임이 아니라 **그 레거시·전시를 현장에서 발굴하는 인터페이스**로 재정의된다. 즉 또 다른 컨셉이 아니라 "다닌 만큼 내가 된다"의 **가장 진실한 형태**. 이번이 끝까지 빌드할 대상.

## 1. 문제 정의
- **주 고객:** 2030, 여행·나들이 잦고 사진 많이 찍고 SNS 기록에 적극적인 사람.
- **PAIN(2축):**
  - **D(영속 공허):** 여행 사진은 인스타 피드·갤러리에 흩어져 휘발된다. **그곳에 다시 갔을 때 내 과거가 거기 없다.** 장소와 내 인생이 연결돼 남지 않는다.
  - **A(발견 결핍):** 그 장소의 진짜 모습 — 남들이 거기서 만든 좋은 순간들 — 을 한데 모아 보지 못한다(인스타는 사람·시간축, 구글포토는 검색).
- **핵심 인사이트:** 사람들은 이미 장소에서 사진을 찍는다(행동 존재). 비는 공간 = **그 사진들을 *장소*에 묶어 평생 쌓고, 재방문 때 되살리고, 집단으로 큐레이션**하는 것.

## 2. 목표 (한 줄)
장소에 사진 순간을 남김 → 평생 누적 → **재방문 시 내 과거 발굴** + **장소 전시 큐레이션**. 개인 레거시를 코어로, 집단 전시를 성장 엔진으로, B2B2C·프리미엄을 수익으로 하는 진짜 서비스.

## 3. 코어 루프
`방문 → 사진 순간 남김(사진+한마디+누구와+무드) → 장소에 누적 → (재방문 시) 과거 발굴/소환 → 전시로 큐레이션(톱) → 자랑·공유 → 남의 전시 발견 → 나도 남김`

## 4. 두 기둥
**① 개인 레거시 (코어 · 싱글플레이어):** 내 사진이 한 장소에 세월별로 쌓인다. 그 자리에 다시 서면(GPS) 과거가 시간층으로 펼쳐짐 — *"3번째 방문 · 2016 봄(연인과) → 2021(혼자) → 2026(가족과)."* 타임홉이지만 **날짜가 아니라 발 딛은 장소가 트리거.** 다른 유저 0명이어도 가치 있음.
**② 장소 전시 (성장 · 멀티플레이어):** 모두의 순간이 그 장소의 큐레이션 갤러리가 됨(톱 N 피처링). 원격으로 둘러보고(어디서나), 현장에선 AR로 발굴. 밀도가 차면 켜지고, 안 차도 ①은 안 죽음.

> **감정 엔진 = "누구와".** 같은 자리·다른 사람·다른 인생 챕터의 대비가 레거시의 눈물 버튼.

## 5. AR 발굴 — 두 가지 경험 (별도 게임 아님, 발굴 인터페이스)
같은 장소의 누적 사진 풀을 현장에서 AR로 만난다. 얕은/깊은 두 층:

**① AR 모자이크 (ambient · 글랜스):** 그 스팟에서 카메라를 들면, 거기서 찍힌 사진들이 **허공에 타일처럼 모자이크로 떠오른다.** 가볍고 즉각적 — "이 자리에 이런 순간들이 쌓였구나"를 한눈에. 현장 발굴의 일상 표면.

**② AR 포털 → 전시회장 (몰입 · 딥다이브):** 허공에 **문(포털)**이 뜨고, 들어가면 **AR 전시회장**이 펼쳐진다.
- **톱 12**를 상단/메인에 피처링(큐레이션),
- 그 아래는 **검색 가능한 아카이브** — *유저 / 날짜 / 내용*으로 찾기 → 톱이 아니어도 모든 순간이 영속,
- **레거시 소환:** 내가 다녀간 스팟이면 **내 사진들을 자동 표시**(세월 지나도 내 것을 띄움).

"왜 AR이냐" = 발 딛은 그 자리에서 과거를 *공간으로* 들춰내는 건 스크롤이 아니라 발굴/입장이어야 울컥하므로. 모자이크 = 글랜스, 포털 전시회장 = 딥다이브. 원격 갤러리(P0)는 같은 풀의 비-AR 브라우즈.
⚠️ *기술 메모: ① 모자이크는 GPS 앵커 + 2D 빌보드로 가볍게 가능(P1). ② 포털·룸스케일 전시회장은 RealityKit/월드트래킹으로 무거운 플래그십(실기기, P2).*

## 6. 전략: cold-start가 구조적으로 풀린다
- **개인 레거시는 N=1로 완결** → 첫날부터 가치(일기처럼). 이중 cold-start 회피.
- **장소 전시는 그 위 멀티플레이어 성장층** → 밀도 차면 켜짐.
- = 강한 소비앱의 정석 쐐기: **싱글플레이어 도구 → 멀티플레이어 네트워크.**
- **해자:** 평생 누적 전환비용(쓸수록 못 떠남) + 장소×시간 UGC 자산 + 큐레이션 IP.

### 7.5 수요 리스크 — 가장 약한 가정과 3층 우회 (핵심)
**가장 약한 가정:** "모르는 사람 사진 보러 스팟까지 온다." → 여기 의존하면 죽음. 아무도 남의 사진 보러 특별히 이동 안 함. **앱이 여행을 *동기부여*하려는 순간 실패.**
**우회 = 수요를 3층으로, 강한 순서대로:**
1. **내 레거시 (load-bearing) ⭐:** 타인 관심 0이어도 성립 — 사람은 *자기* 기억엔 무조건 관심. 코어를 여기 둠으로써 이 위험을 통째로 우회.
2. **원격 탐색 (검증된 수요):** 여행 *전* 남의 장소 사진 보기 = 인스타 위치태그·구글맵·블로그 후기로 이미 거대. 현장 이동 불필요.
3. **현장 = enrich, not motivate:** 이미 간 곳에서 모자이크·발굴은 보너스 손맛. "사진 보러 와라"는 1차 CTA 금지.
**타인 사진이 먹히는 조건:** 큐레이션(베스트만)·효용(숨은 스팟)·사회적 근접(친구·동행)·여행전 영감. 순수 "낯선 이 감상"엔 베팅 ❌.
**검증 순서(제주 PoC):** ① 레거시 공명(재방문 소환에 울컥/공유?) ② 원격 브라우징 ③ "타인 위해 이동"은 load-bearing에서 제외·후순위.

## 10. 수익모델 (P1)
- **스폰서 전시/장소(B2B2C):** 가게·브랜드·지자체가 그 장소 전시를 후원·큐레이션(방문 유도).
- **프리미엄:** 무제한 백업·고화질·고급 레거시(영상 리캡·연표) 구독.
- 검증: 잠재 스폰서 LOI 1건.

### 10.5 비즈니스 모델 — 구(임의보물) vs 신(순간사진)
보물 재정의 = **취약한 위치게임 → 방어가능한 콘텐츠·기억 플랫폼** 전환.
| 차원 | 구: 임의보물 등록/찾기 | 신: 순간사진=보물 |
|---|---|---|
| 공급 | 일부러 만들어 숨김(마찰↑·빈지도) | 이미 찍는 사진(한계비용0·진짜) |
| 수요 | 임의 스티커 신기함 소멸 | 진짜 순간+내 과거(내재·영속) |
| 네트워크효과 | 약한 양면·스팸 | 데이터NE + 개인 레거시 락인 |
| 해자 | 복제 쉬움 | 장소×시간 아카이브 + 평생 전환비용 |
| 수익 | 스폰서 보물(광고) 단일 의존 | 구독+B2B전시+커머스+B2G 다층 |
| LTV/비용 | 신기함 소멸→저LTV | 평생 락인 고LTV(단 저장비↑) |
| 즉시성 | 헌트 도파민 즉각 | 레거시 늦게 터짐(→7.5 훅) |
| 모더레이션 | 스티커 가벼움 | 진짜 사진=초상권/프라이버시 부담 |

**수익 4문(신):** ① 구독(무제한 백업·고급 레거시 = 반복매출, *저장비용이 곧 상품*) · ② B2B 스폰서 전시(가게·관광공사, 진정성) · ③ 커머스(포토북·프린트) · ④ B2G/관광 데이터.
**유사 패턴:** 인스타 × iCloud/구글포토(저장 구독) × Foursquare × Timehop × Letterboxd-for-places. 전부 검증된 수익 패턴.

## 13. MVP 범위 (YAGNI)
- **✅ P0 (싱글플레이어 코어 + 원격 전시):** 사진 순간 남기기(사진+한마디+누구와+무드) · **재방문 레거시 소환**(비-AR 타임라인 UI) · 장소 전시 원격 갤러리(톱 N) · 지도 · **클라우드 백업** · 온보딩 첫 순간 · 안전(현장인증·신고·AI필터)
- **⏳ P1:** **AR 모자이크**(허공 사진 타일 · 현장 글랜스 발굴) · 톱 N 큐레이션 고도화(투표/AI) · 전시 검색(유저/날짜/내용) · 동행자 공유·태그 · 여행 정체성(Wrapped) · "1년 전 오늘" 리캡 푸시 · 스폰서 전시
- **🔮 P2(플래그십):** **AR 포털 → 전시회장**(몰입 룸스케일 · 검색·레거시 소환 in-AR) · 그룹/동행 레이어 · 영상 리캡 · 코스 단위 전시 · 추천 고도화

## 14. 온톨로지 (핵심 엔티티)
| Entity | Fields | Relationships |
|---|---|---|
| User | 닉네임, 여행정체성, 여정 | leaves Moments; owns Legacy |
| Place(장소) | 좌표, 이름, 전시 | aggregates Moments → Exhibition |
| **Moment(사진 순간)** | 사진, 한마디, **동행자**, 무드, GPS, 시각, 공개범위 | left by User at Place |
| Exhibition(전시) | 톱 N, 기여자, 커버 | curated from Place's Moments |

| Companion(동행) | 관계(연인/가족/친구/혼자) | tags Moments |
| Visit(방문) | 시각, 위치인증 | records presence |
